## Topic suggeriti per la prima versione

- CI4 routing: filters, group, route-level auth
- Database: Query Builder vs raw, prepared statements
- Validation Library: rules custom, validation sui form
- CSRF protection: enabled in `Config\Security`
- Encryption Service: key in env, no DEFAULT_KEY committed
- Session: driver `database` o `redis`, no `files` su shared concorrente
- ENVIRONMENT='production' in .env, CI_DEBUG=false
- Versione CI4 supportata
- HMVC patterns / module organization
